# vaper

A minimal PDF viewer for Visual Studio Code. Open any `.pdf` file normally, run **Vaper: Open PDF**, or search arXiv from the Command Palette.

## Features

- Searches arXiv directly with **Vaper: Search arXiv for Paper** and shows recently opened papers
- Opens PDFs in an editor tab
- Page navigation and keyboard navigation
- Fit-to-window and zoom controls
- Selectable, copyable PDF text
- Citation previews on hover for PDFs with linked bibliography entries
- Page rotation and reload
- Restores page, zoom, and rotation per editor

## Credits

Vaper uses Mozilla's [PDF.js](https://github.com/mozilla/pdf.js) and was inspired by [LaTeX Workshop's PDF viewer](https://github.com/James-Yu/LaTeX-Workshop). It includes no LaTeX or SyncTeX integration.
